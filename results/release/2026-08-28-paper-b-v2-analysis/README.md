# Paper B v2 derived analysis

This compact release contains the manuscript-neutral outputs added for the v2
revision, *Batched Lagrangian Bounds for Robust Multiple-Choice Knapsack*.
It is derived entirely from the immutable 9 August 2026 release in the adjacent
`2026-08-09-paper-b-final-r5/` directory.

`operating-region.csv` combines 122 instance rows from the primary,
robustness, stress, coefficient-transfer, and pricing-derived panels.
`operating-region-summary.json` records the input hashes, post-hoc log
correlations, and pricing-panel fixed-LP fractions. The four PNG files are the
current evidence and mechanism visualizations generated by the public scripts.

The operating-region analysis is descriptive and hypothesis-generating. It is
not a trained method selector, a causal analysis, or a native
objective-uncertainty experiment. The adverse pricing and integer-integration
results in the frozen base release remain part of the evidence.

No manuscript source, manuscript PDF, submission package, or raw third-party
data is included.
